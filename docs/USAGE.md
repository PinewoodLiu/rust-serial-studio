# 使用指南

## 操作细节

- **串口发送**：设置与设备一致的串口参数，再打开连接。`Ctrl+Enter` 发送单条编辑区的内容，`Ctrl+L` 清空显示。
- **界面布局**：左侧是连接设置，中间是接收监视器及底部的单条/文件发送，右侧常驻多条指令表格。三条带握柄的分隔条分别调整连接区宽度、指令区宽度、接收/发送区高度。双击分隔条恢复默认大小，尺寸随参数保存。
- **多条表格**：列依次为 HEX、字符串、点击发送（注释）、发送次数、延时 ms。整组始终从上到下执行，箭头改变行的位置。每条发送次数 N 表示连续发送 N 次后执行下一条，0 表示跳过；本条的延时作用于每次发送之后。例如 A=3 次、B=2 次，每轮发送 `AAABB`。单击本条注释按钮也遵循本条次数，0 次时提示先设置次数。双击字符串或其右键菜单可编辑注释，点击字符串选中行后可用 ＋、－、↑、↓ 添加、删除、调整行位置。旧 JSON 的启用/停用状态分别迁移为 1/0 次，SSCOM INI 导入同理。
- **循环轮数**：右侧顶部勾选“循环发送”后，“循环轮数”表示整组执行 N 轮后自动停止，0 表示不限；未勾选循环时只执行一轮。每条次数与整组轮数独立，例如 A=3 次、B=2 次、整组 2 轮，总共发送 10 次。
- **单条发送次数**：底部单条“发送次数”用于定时发送，N 次后自动停止，0 表示不限；底部手动点击“发送”仍只发送一次。运行时显示已完成次数/轮数。
- **Modbus 示例**：勾选 HEX，输入 `01 03 00 00 00 02`，选择 Modbus CRC16；实际发送 `01 03 00 00 00 02 C4 0B`。
- **校验顺序**：解析输入 → 排除帧头/帧尾后计算校验 → 将校验插入帧尾前 → 最后追加换行。排除长度以**字节**计。Modbus CRC16、CRC32 为低字节在前；CRC16/XMODEM 为高字节在前。
- **多条指令**：仅执行有内容且发送次数大于 0 的指令。每条的延时表示本次发送完成后到下一次发送之间的间隔，最短 10 ms；单条定时与多条循环由后台线程调度，不保证硬实时精度。
- **共享选项**：多条指令共用编码、转义、换行、校验；每条的 HEX 独立设置。文件发送完全保持原始字节，不应用这些选项。发送任务运行时不能插入其他发送，以避免数据交错。
- **TCP 服务端**：默认只监听 `127.0.0.1`；需要远程访问时自行填写网卡地址。每次只接受一个客户端，对端断开后需重新打开监听。IPv6 地址用 `[::1]:8080` 格式。
- **UDP**：本地和远端端口通常应不同；接收仅限指定远端。每次手动发送为一个数据报，最大 65507 字节；文件分块为多个数据报。UDP 不提供送达、重传或顺序保证。
- **接收分包**：串口/TCP 将接收空闲间隔小于设定值的读取块合并显示，默认 20 ms，可在“数据监视器”的“分包间隔”中调整（1～1000 ms，立即生效）。例如 `H` 与 3 ms 后的 `ello, serial!` 会合并成一条 `Hello, serial!`、14 B。间隔是显示规则，不是协议帧解析；持续数据最多每 200 ms 或 65536 B 显示一块，设置大于 200 ms 时最长等待随之延长。UDP 保留每个数据报的边界。断开时仍会显示尚未到期的接收数据。
- **显示与统计**：所有字节大小始终用 B，速率始终用 B/s，不自动转换为 KiB/MiB。列表将换行与控制字符显示为可见标记，超过 260 字符的记录点击查看全文。UTF-8/GBK 解码保留跨块字符状态，未完成的字符可能显示在下一条记录。原始 RX 文件与计数在读取时直接记录，不受显示分包间隔影响。
- **采集与日志**：显示缓存最多约 4 MiB 或 3000 条，旧记录自动移除；日志导出只包含当前缓存。长时间接收请选择“接收数据到文件”，只保存 RX 原始字节，不含 TX、时间戳或额外分隔符。文件每秒及停止/断开时刷新。可暂停显示，后台仍继续接收和保存。
- **高流量**：通信与 UI 使用有界队列。界面处理不及时会省略显示块并提示数量，RX/TX 字节计数与原始接收文件独立于显示。存储太慢、设备/驱动缓冲溢出和 UDP 网络丢包仍可能造成采集不完整。
- **配置**：默认保存到 `%APPDATA%\RustSerialAssistant\settings.json`，不自动恢复连接或启动发送。配置损坏时显示错误并使用默认值，保留原文件；点击“保存参数”会覆盖该文件。
